
### 2.2 通道 1：Wi-Fi Direct HTTP 文件传输（眼镜 → 手机）

**核心类**: `AlbumDepository` (`com.glasssutdio.wear.depository`)

这是 **最核心的下载功能**，用于从智能眼镜拍摄的照片/视频/音频传输到手机。

#### 2.2.1 传输流程

```
步骤 1: 手机连接到眼镜的 Wi-Fi (通过 Wi-Fi Direct P2P)
       ↓
步骤 2: 从眼镜 HTTP 服务下载 photo.txt 文件清单
       URL: http://{glassDeviceWifiIP}/files/photo.txt
       (如果是日志模式: http://{glassDeviceWifiIP}/files/log/photo.txt)
       ↓
步骤 3: 解析 photo.txt，每行一个文件名，构建下载队列
       URL: http://{glassDeviceWifiIP}/files/{fileName}
       ↓
步骤 4: 逐个文件下载（队列模式，非并行）
       ↓
步骤 5: 根据文件类型进行后处理
       - 图片(.jpg/.jpeg): 直接保存
       - 视频(.mp4/.avi): 提取陀螺仪数据 → EIS 防抖处理
       - 音频(.opus): Opus → PCM → MP3 转码
       - 无扩展名文件: 检测 "Thisadir" 魔术字节判别类型
```

#### 2.2.2 关键代码逻辑

**photo.txt 下载与解析** (`readPhotoFile`):
```kotlin
// 1. 下载 photo.txt 文件清单
AndroidNetworking.download(url, dirPath, fileName)
    .setTag("photo.txt")
    .setPriority(Priority.MEDIUM)
    .build()
    .startDownload(listener)

// 2. 逐行解析，构建下载 URL
for (line in File(path).readLines()) {
    val url = "http://${glassDeviceWifiIP}/files/${line}"
    fileQueue.putLast(PictureDownloadBean(url, line))
}
```

**文件下载** (`downloadGlassFile`):
```kotlin
// 队列式逐文件下载
val bean = fileQueue.peekFirst()
AndroidNetworking.download(bean.path, albumDir, bean.fileName)
    .setTag("download_file")
    .setPriority(Priority.MEDIUM)
    .build()
    .setDownloadProgressListener { bytesDownloaded, totalBytes ->
        // 计算下载速度
        val speed = calculator.calculate(bytesDownloaded)
        // 回调进度
        listener.fileProgress(fileName, progress)
        listener.wifiSpeed(speed)
    }
    .startDownload(onComplete = {
        // 下载完成 → 后处理（防抖/转码）→ 继续下一个
        fileQueue.removeFirst()
        downloadGlassFile() // 递归下载下一个
    }, onError = {
        failCount++
        if (downloadErrorCount <= 2) {
            downloadGlassFile() // 重试（最多3次）
        } else {
            fileQueue.clear() // 放弃
        }
    })
```

#### 2.2.3 自定义二进制文件格式

无扩展名的视频文件使用了 **自定义的复合文件格式**，末尾附加了陀螺仪和行曝光数据：

```
┌──────────────────────────────────────────────┐
│ MP4 视频数据  (长度: mp4Length)                │
├──────────────────────────────────────────────┤
│ 帧时间戳数据  (长度: frameFileNameLength)      │
├──────────────────────────────────────────────┤
│ 陀螺仪数据    (长度: gyroLength)              │
├──────────────────────────────────────────────┤
│ 尾部元数据区 (从文件末尾向前解析):              │
│   [-8]  魔术字节 "Thisadir" (识别标记)         │
│   [-16] 文件数量 (8 bytes hex string)         │
│   [-24] 陀螺仪文件名长度 (8 bytes hex string)  │
│   [-56] 陀螺仪文件名 (32 bytes, 0-padded)     │
│   [-64] 帧文件长度 (8 bytes hex string)        │
│   [-96] 帧文件名 (32 bytes, 0-padded)         │
│   [-104] MP4 长度 (8 bytes hex string)        │
└──────────────────────────────────────────────┘
```

解析后将复合文件拆分为：MP4 视频 + 帧时间戳 + 陀螺仪数据，然后通过 AllWinner EIS 引擎进行电子防抖处理。

### 2.3 通道 2：OTA 固件下载（云端 → 手机）

**核心类**: `OTAViewModel` + `OTADepository`

#### 2.3.1 OTA 检查流程

```
1. 调用 checkOta(hwName, fmVersion, wifiNotBle)
   ↓
2. 请求后端 API:
   - 国际版: POST https://www.qlifesnap.com/glasses/app-update/last-ota
   - 国内版: POST https://www.qlifesnap.com/glasses/app-update/last-ota/china
   ↓
3. 收到 FirmwareOtaResp 响应
   ↓
4. 判断是否需要下载:
   - openOrNot == 3 (调试模式) → 下载
   - openOrNot == 2 (正式模式) → 下载
   ↓
5. 下载固件
```

#### 2.3.2 固件下载 URL 格式

```
BLE 固件:  {downloadUrl}  → 文件名: {version}.bin
Wi-Fi 固件: https://qcwxfactory.oss-cn-beijing.aliyuncs.com/bin/glasses/{hwVersionWifi}.swu
            → 文件名: {version}.swu
```

> **关键发现**: Wi-Fi 固件下载 URL 使用阿里云 OSS（`oss-cn-beijing.aliyuncs.com`）

#### 2.3.3 OTA 下载特性

- **断点续传**: Wi-Fi 固件支持通过数据库 (`OtaFileEntity`) 检查已下载状态
- **进度通知**: 通过 `LiveData` + `EventBus` 双通道通知 UI
- **1% 粒度**: 进度以每 1% 变化为单位发送通知

```kotlin
// 进度回调逻辑
val progress = (100 * bytesDownloaded / totalBytes).toInt()
if (progress > lastProgress && progress - lastProgress == 1) {
    _uiState.postValue(FirmwareUI(0, progress, fileName, false))
    EventBus.post(OTAFileStatusEvent(3, progress, false, fileName))
}
```

### 2.4 通道 3：云端资源批量下载

**核心类**: `DownloadUtils` (`com.glasssutdio.wear.home.download`)

使用 [OkDownload](https://github.com/nicegram/OkDownload) (liulishuo) 库进行批量资源下载，主要用于 **表盘图片/视频预览图** 资源。

#### 2.4.1 批量下载策略

```kotlin
// 1. 将下载列表分组（每组最多 10 个）
val chunks = averageAssign(list, list.size / 10)

// 2. 每组构建 DownloadContext 并行下载
for (chunk in chunks) {
    val queueSet = DownloadContext.QueueSet()
    queueSet.parentPathFile = getVideoDirFile()   // {externalFilesDir}/video/
    queueSet.minIntervalMillisCallbackProcess = 1000

    for (item in chunk) {
        val task = DownloadTask.Builder(item.preImageUrl, videoDirFile)
            .setFilename(fileName)
            .setMinIntervalMillisCallbackProcess(64)
            .setPassIfAlreadyCompleted(false)  // 不跳过已完成
            .setPriority(10)
            .setConnectionCount(1)             // 单连接
            .setReadBufferSize(8192)           // 8KB 缓冲
            .build()
        builder.bindSetTask(task)
    }

    // 3. 并行启动
    builder.build().startOnParallel(QueueImageListener())
}
```

## 五、视频后处理流水线

```
原始文件 (从眼镜下载)
    ↓
文件类型识别:
    ├── 有扩展名 → 按扩展名判断 (.jpg=图片, .mp4=视频, .opus=音频)
    └── 无扩展名 → 读取末尾 8 字节, 检查 "Thisadir" 标记
            ├── 匹配 → 视频类型 (含陀螺仪数据)
            └── 不匹配 → 图片类型
    ↓
视频处理分支:
    1. 拆分复合文件 → MP4 + 帧时间戳 + 陀螺仪数据
    2. 提取第一帧 → 判断横竖屏
    3. 加载 EIS 配置 (AW_EIS110_V821_QC_A06.cfg)
    4. 初始化 EIS 引擎 (eisInit)
    5. 执行防抖 (eisYuv2Mp4)
    6. 保存到系统相册
    ↓
音频处理分支:
    1. Opus 文件 → JieLi OpusManager 解码 → PCM
    2. PCM → MP3 转码 (PcmToMp3Kt)
    3. 保存到 MediaStore
```

## 六、关键发现总结

### 6.1 安全相关

- API 使用自定义签名机制 (`SignatureInterceptor` + `SimpleSigner`)
- 加密密钥通过 `/encryption/getKeys` 动态获取
- OTA 固件未使用 HTTPS 验签（直接从 Aliyun OSS 下载）

### 6.2 域名汇总

| 域名 | 用途 |
|------|------|
| `www.qlifesnap.com` | 主 API 服务器 |
| `qcwxfactory.oss-cn-beijing.aliyuncs.com` | OTA 固件存储 (Aliyun OSS) |
| `api1.qcwxkjvip.com` | 备用 API 端点（华为渠道） |
| `china.qcwxwire.com` | 国内专用 API 端点 |

### 6.3 Wi-Fi 传输协议

眼镜端运行一个 **HTTP 文件服务器**，端口未明确指定（默认 80），提供如下接口：

```
GET /files/photo.txt          → 文件清单
GET /files/{fileName}         → 下载文件
GET /files/log/{fileName}     → 下载日志文件
```

### 6.4 硬件信息

- **芯片**: AllWinner V821（全志 V821）
- **EIS 配置**: `AW_EIS110_V821_QC_A06.cfg`
- **蓝牙**: 杰理(JieLi) BLE + Opus 音频编解码
- **固件格式**: BLE 固件为 `.bin`，Wi-Fi 固件为 `.swu`（SWUpdate 格式）
